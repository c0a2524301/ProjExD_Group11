# 逃げろ工科トン

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1
* 必要なものがあれば追記してください（非推奨）

## ゲームの概要
* 迫ってくる天井から常に逃げ続けろ！
* 参考URL：[サイトタイトル](https://www.4gamer.net/games/560/G056032/20210322001/)

## ゲームの遊び方
* 左右の矢印キーを使って迫ってくる天井を避け続ける
* 潰れたらゲームオーバー
## ゲームの実装

### 共通基本機能
* 背景画像と主人公キャラクターの描画

### 分担追加機能
**BGMの実装**: 
  -  臨場感のあるBGMのループ再生と、ゲームオーバー時の自動停止処理。
- **効果音（SE）の追加**:
  - 壁が地面に激突する瞬間のインパクト音（「ドン！」）
  - 壁を回避してスコアが「+1」されたときのスコアアップ音
  - ダッシュ移動を開始したときのダッシュ音(森田)
